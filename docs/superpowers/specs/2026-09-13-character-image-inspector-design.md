# 角色卡图片参数解析与导入设计

## 目标

在角色卡页面内加入本地图片参数解析功能，读取 Stable Diffusion/ComfyUI 图片元数据，预览原图与解析结果，并一键创建角色卡。角色名默认使用图片文件名（去掉扩展名），导入前可修改。

## 方案

复用项目现有 Pillow 元数据读取与角色卡数据库，不嵌入外部 Inspector 的 Vite 前端。新增角色解析 API 与前端面板：上传图片到内存，解析 PNG Info、EXIF parameters、ComfyUI prompt/workflow；解析完成后将临时预览与字段返回页面。确认导入时，后端再次接收图片和字段，校验后写入角色记录及本地预览目录。

## 数据映射

- 图片：保存为 `character_previews/{character_id}{ext}`，复用角色卡的预览图字段。
- 正向 Prompt：填入角色卡 `appearance`，保留完整原文。
- LoRA：从 `<lora:name:weight>` 提取第一个 LoRA 名称和权重。
- 触发词：从图片参数中提取 LoRA 触发词不可可靠推断时保持为空，由用户在导入前编辑。
- 负向 Prompt、完整元数据：写入角色卡备注，带来源标识，避免扩展数据库表。

## 界面与风格

角色卡页面新增同现有深色紫蓝主题一致的解析面板。面板分为上传区、图片预览、解析字段和导入按钮；角色名、LoRA、权重、触发词、外貌/Prompt、备注均可编辑。解析失败显示可操作错误，但允许仅导入图片。

## 安全与错误处理

仅接受 png/jpg/jpeg/webp，限制 20 MB；只在本地处理，不联网；文件名只用于默认名称，写入前清理路径字符；同名角色沿用现有更新逻辑，不覆盖预览图直到导入成功。

## 验证

增加 API/解析单元测试：PNG Info 读取、ComfyUI workflow 文本提取、LoRA 提取、解析失败、导入成功与预览文件保存。运行角色卡和图库相关测试，并通过本地 HTTP 页面检查新面板和导入按钮。
