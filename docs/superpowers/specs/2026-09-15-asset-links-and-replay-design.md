# Night Wardrobe 第二、三阶段设计

## 目标

在不重写应用和不改变生成流程的前提下，让输出图片成为可复用资产入口，并提供轻量关联、复刻操作和快捷键。

## 数据与 API

- 复用 `output_images`、`characters`、`lora_cards`、`output_loras`。
- 新增只读聚合查询：按图片返回匹配角色、LoRA、出现次数、最近使用时间。
- 角色列表返回使用次数和最近使用图片；无关联时返回空数组和 0。
- 任何新增列通过启动迁移补齐，旧数据库不丢数据。

## 输出详情 UI

- 增加关联角色区和 LoRA 关联状态。
- 保留复制 Prompt、Negative Prompt、标签、触发词、画师串、工作流和填入工作台入口。
- 增加“保存为角色卡”入口，复用现有角色创建接口，默认预填当前图片解析数据。
- 增加复刻建议摘要：当前角色、LoRA、关键标签和可用工作流。

## 快捷键

- `Ctrl+C` 在详情焦点不位于输入框时复制当前正面 Prompt。
- `Ctrl+Enter` 填入工作台。
- `Space` 预览当前图片；输入框、文本域和对话框内不拦截。
- 快捷键只作用于 Outputs 详情页，并提供按钮提示。

## 测试与兼容

覆盖聚合查询、无关联图片、角色统计、保存角色卡预填、快捷键事件和既有版本/LoRA/summary API。运行 compileall 与完整 pytest；不新增外部依赖或网络请求。
